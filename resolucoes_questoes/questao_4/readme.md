# 💰 Questão 4 - Análise de Clientes de Elite (PostgreSQL)

## 📌 Visão Geral do Projeto

Dando continuidade ao pipeline de dados da empresa fictícia **LH Nautical**, esta etapa realiza a **análise de clientes de elite** — identificando os **10 clientes com maior Ticket Médio** e, em seguida, filtrando aqueles que compraram produtos de **13 ou mais categorias distintas**. Além de encontrar a categoria mais vendidas para cada um desses clientes, a consulta SQL é estruturada utilizando **CTEs independentes** para facilitar a leitura e manutenção do código.
